# Loom Demo Script

Use this when recording at https://loom.com/canvas.

1. Start on the live deployed URL.
2. Say: "This is TaskFlow, a self-hostable mini Trello for remote teams."
3. Log in with `user` / `User@123`.
4. Show multiple boards in the left panel.
5. Open a board and create a task with title, description, assignee, due date, and priority.
6. Drag the card from To Do to In Progress to Done.
7. Show search and priority filter.
8. Log out and register a new member account.
9. Log in with `admin` / `Admin@123`.
10. Show Admin Users: add user, edit role, delete user.
11. Open a second browser window logged in as member and show realtime updates.
12. Explain role permission: admin manages all cards, members manage only own or assigned cards.
13. Show README with live demo link, credentials, setup, and deployment instructions.
